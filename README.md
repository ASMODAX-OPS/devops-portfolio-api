# DevOps Portfolio API

Proyecto de portafolio DevOps: API REST construida con FastAPI, contenerizada con Docker,
desplegada con CI/CD en GitHub Actions, infraestructura en AWS gestionada con Terraform,
orquestada en Kubernetes con Helm, y monitorizada con Prometheus + Grafana.

## Estado del proyecto
🚧 En construcción — Fase 1: Preparación del entorno.

## Stack
- API: Python + FastAPI
- Base de datos: PostgreSQL
- Contenerización: Docker / Docker Compose
- CI/CD: GitHub Actions
- IaC: Terraform (AWS)
- Orquestación: Kubernetes + Helm
- Observabilidad: Prometheus + Grafana
